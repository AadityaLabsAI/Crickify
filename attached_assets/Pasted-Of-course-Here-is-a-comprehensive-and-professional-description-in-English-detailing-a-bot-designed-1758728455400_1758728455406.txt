Project Concept: The Live Match Centre TELEGRAM Bot
Core Philosophy: To transcend the limitations of a typical chatbot and create a dynamic, self-updating "Live Match Centre" inside a Telegram chat. The goal is to replicate the immersive and data-rich experience of a premium sports website like Cricbuzz, eliminating the need for users to type commands or even leave the app for a complete match overview.

The Centrepiece: The "Live Match Dashboard"
This is the bot's signature feature. Instead of sending multiple new messages for every update, the bot creates a single, persistent message at the start of a match. This message then edits itself in real-time every 15-20 seconds to reflect the current state of the game. The user gets a continuously evolving, glanceable dashboard.
This "Live Match Dashboard" will be visually organized using emojis and text formatting to be attractive and easy to read. It will contain:
1. Match Header:
Displays team flags, names, the tournament name, and the match format.
Example: 🏆 ICC T20 World Cup | Final 🇮🇳 IND vs 🇦🇺 AUS
2. The Scoreboard:
Shows the batting team's score, wickets, and overs in a clean, bold format.
Example: 🏏 **IND: 185/3 (19.2 ov)**
3. Live Match Statistics:
Crucial data that is constantly updated.
Current Run Rate (CRR): 9.5
Required Run Rate (RRR): 9.0 (or First Innings Score)
Partnership: 45* (22 balls)
4. The Winning Probability Meter:
A professional, data-driven feature that dramatically enhances the experience. The bot will display the win percentage for each team, which will fluctuate with every boundary and wicket.
Example: 📈 **Win Probability: [🇮🇳 IND: 75%] [🇦🇺 AUS: 25%]**
5. Ball-by-Ball Commentary Snippet:
Shows the outcome of the last 2-3 deliveries, providing a live commentary feel.
Example: Last Few Balls: [ 6️⃣ | 1 | W | 4 | 1 ]
6. Live Status Bar:
A clear, concise text update describing the current situation of the match.
Example: STATUS: India needs 12 runs in 8 balls to win.

Supporting Functions (Fully Button-Driven)
To ensure a "zero-typing" experience, the entire bot is controlled via an interactive button menu.
1. The Main Menu (/start):
A persistent menu with four buttons: [🏏 Live Matches], [📅 Schedule], [🔔 My Alerts], and [📊 Player Stats].
2. One-Tap Live Experience:
Pressing [🏏 Live Matches] shows current games as buttons.
Tapping a match button instantly launches the "Live Match Dashboard" for that game. No further commands are needed.
3. Automated Pre- & Post-Match Hub:
Pre-Match: For any subscribed match, the bot automatically sends a single, beautifully formatted message 30 minutes before the start, containing the Toss Result, Playing XIs for both teams, and a "Who will win?" poll.
Post-Match: After the match, this same message edits itself to become a Final Match Summary, displaying the result, Player of the Match, and top performers.
4. "Tap-and-Subscribe" Alerts:
Users browse the [📅 Schedule] and tap a [🔔 Notify Me] button next to any match they wish to follow. The bot then offers personalized alert options ([Wickets], [Milestones], etc.) also via buttons.
This design philosophy ensures the bot is not just a tool for information retrieval, but a sophisticated, engaging, and fully automated companion that delivers a professional sports app experience directly within the convenience of a Telegram chat.
